# HFSS 原始模型接入与基线验收

## 1. 几何验收

- 槽深从金属板顶面向下定义，不得把整块下板贯穿成普通矩形波导。
- 空气求解域同时覆盖槽腔和金属板之间的空气间隙。
- 所有销钉与空气域有真实接触界面，不能落在未求解区域。
- 销钉不得与相对金属板发生非预期穿透；空气间隙与设计尺寸一致。
- 原模型、参数化副本和改进模型分别保存，禁止覆盖原模型。
- 待扫描量必须是 HFSS design variables，名称与 CSV 表头完全相同。

## 2. 端口与求解验收

- 端口截面覆盖完整可传播空气截面，积分线方向一致。
- 参考通道与移相通道采用相同端口参考面及 de-embed 设置。
- 多模结构应请求足够模式并检查高阶模功率；最终报告明确所用模式。
- 扫频范围、类型与采样密度符合研究目标，异常尖峰附近加密。
- 自适应网格频率、最大 Delta S、最大 passes 均被记录，并保存收敛历史。
- setup 和 sweep 名称与命令行参数完全相同。

## 3. 基线结果门槛（当前 GGW -45° 案例）

只有同时满足以下条件，才开展结构优化：

- 参考通道在 30–35 GHz 内 `S11 < -15 dB`、`S21 > -1 dB`。
- -45° 通道相对参考通道的平均移相接近 -45°，最大误差不超过 ±7°。
- 改变关键尺寸时响应连续且物理可解释，不能只有 0°/180°端口翻转。
- 同一模型重复求解的幅度差不超过 0.2 dB、相位差不超过 2°。

这些数值是当前研究案例的门槛，不是工具的硬编码限制。其他项目应建立自己的验收表。

## 4. 异常频点证据

对异常频点保存基模与高阶模功率、场分布、表面电流、局部能量集中和相邻正常频点对照。仅凭 S 参数尖峰不能断言局部谐振。

## 5. 自动化放行顺序

1. GUI 中人工验收原工程并关闭 AEDT。
2. `--dry-run` 验证路径、run ID 和变量值。
3. build-only 单点，重新打开副本检查变量是否实际生效。
4. solve 单点，检查收敛、端口模式和 Touchstone。
5. 重复性测试通过后，再执行小范围批量扫描。
